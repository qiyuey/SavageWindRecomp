# Repository instructions

## Personal fork workflow

This repository uses the `test` branch in the qiyuey fork. Follow [docs/FORK-MAINTENANCE.md](docs/FORK-MAINTENANCE.md). Create focused new commits; do not amend the historical local FIX by default. `origin` is the personal fork, `upstream` the original project. Preserve published history and custom SDL3 integration. Publish only when authorized; do not push directly to upstream. Keep private game content and generated artifacts untracked.
